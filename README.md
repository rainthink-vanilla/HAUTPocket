# 口袋工大 · HAUTPocket

河南工业大学非官方 Android 校园助手，是参考 **[ZZUPocket](https://github.com/3beuml/ZZUPocket)** 的河南工业大学版**复刻 / 适配实现**。默认莲花街校区，同时支持嵩山路校区。

**特别感谢 [3beuml](https://github.com/3beuml) 开源 ZZUPocket。** 原项目把课表、宿舍用电和校园服务集中到一个校园助手中的设计，为本项目的功能规划、离线体验与技术选型提供了重要参考。

本项目作为独立仓库维护。业务代码针对河南工业大学重新实现，复用了部分构建配置与 Gradle Wrapper；功能和界面并非与 ZZUPocket 完全相同，也不代表原作者参与或认可本项目。

[下载 1.0.1 正式版](https://github.com/rainthink-vanilla/HAUTPocket/releases/tag/v1.0.1) · [原项目 ZZUPocket](https://github.com/3beuml/ZZUPocket) · [课表方案对比](docs/TIMETABLE-COMPARISON.md)

**当前正式版为 1.0.1。修复教务课表白屏、“第N周”漏解析与内部框架跳转误报，改进教务和图书馆登录会话保存，并使用新的应用图标。安装包采用关闭调试、R8优化的 Release 构建与发行签名，详见[发布说明](docs/RELEASE-v1.0.1.md)。教务登录、页面显示和导入预览已通过用户本机验证；智能水电仍待真实账户端到端联调，正式版本号不代表所有第三方接口均已验证。**

## 功能与状态

| 功能 | 当前实现 | 验证边界 |
|---|---|---|
| 双校区 | 莲花街 / 嵩山路切换；手工房间与读数按校区隔离；在线房间由用户确认归属 | 本地存储与计算可单元测试，界面待设备检查 |
| 课表 | 官方教务网页导入，或大学课表 .md/.json 文件导入；日列表与七天周表可切换，连续同课程合并为跨节块、冲突并排，支持校历、作息和导出 | 文件互通自动验证；1.0.1用户确认本机教务登录、课表显示与导入预览正常，其他账户及双校区作息仍需核验 |
| 智能水电 | 输入本人校园卡账号，查询已绑定房间，再读取各房间的水电表计 | 使用社区记录的接口和河南工业大学历史代码 43，当前租户有效性待真实账号验证 |
| 在线读数 | 显示设备名称、余额、今日用量、累计购入、状态和查询时间，保存kWh用电趋势 | 电量采样按用户确认统一为kWh，余额保留服务原文；缓存不代表实时值 |
| 手工记录 | 房间标签、可选服务端 ID、独立表计、剩余量、期间充值量和区间使用量 | 充值量未知时不计算消费；不和在线不同单位的读数混算 |
| 校园卡 | 集中入口，可唤起已安装的完美校园；否则显示校方说明 | 本版没有原生校园卡余额/流水接口 |
| 校园服务 | 唤起已安装的云上工大 App，提供教务、图书馆及学校帮助页 | 云上工大跳转待真实设备验证；教务等网页可能需要校园网 |
| 专注 | 15/25/45 分钟计时、完成记录、后台通知、取消与重启恢复 | 需要本人开启系统通知；Android12+授权准时提醒后使用精确闹钟，否则通知可能延迟；强制停止和系统后台限制仍会影响提醒 |

不提供自动充值、校园卡转账、自动抢座。底部导航栏的“图书馆”独立页面集中提供图书查询与座位预约。

0.8.0的图书查询使用独立Compose界面：常驻搜索框、真实封面与放大预览、书目卡片、集中展示馆藏位置、索书号和借阅状态。底层复用官方馆藏网页会话提供数据，“完整检索”可切换到同一官方页面继续筛选、排序、地图和认证。用户已在手机搜索“计算机”取得20条结果，点击首本后显示3份馆藏。封面来自官网实际图片，缺图或加载失败明确显示“暂无封面”，该位置不提供放大；官网占位图保持原样。新版与应用共用主题、文字颜色和字体设置。

座位预约内嵌手机实际跳转的官方网页，不携带捕获到的token，认证按官方流程进行，同时保留“从云上工大打开”入口。区域和座位界面支持名称搜索、只看有余座、桌号/座位号搜索和只看可选，保留官方真实座位编号与确认流程，可切回原版。用户确认学校统一认证登录后可返回图书馆系统并进行选座；0.5.3增加认证返回首页后的一次选座回跳，以及“继续选座”按钮。首次使用和会话过期需要本人登录，完整预约提交未代用户验证。详见 [官方入口调整通知](https://lib.haut.edu.cn/info/1162/12015.htm)。

## 首次使用

1. 从正式发布页下载安装 APK，顶部默认选择“莲花街”，可切换“嵩山路”。旧版用户请先覆盖安装，不要为升级而卸载应用。
2. “设置 → 导入课表 → 从教务网页导入”，在学校页面登录，进入“学生课表查询”，选好学年/学期，再点底部“导入当前学期课表”。确认预览后才替换原课表。
3. 右上角设置页可切换校区、字体、主题颜色和文字颜色，并管理课表导入导出。主题与文字均可打开调色盘，通过拖动色板、色相条、常用色或HEX输入选择颜色；文字保留自动、高对比、暖色、冷色。调色时应用和示例实时预览，点“应用”才保存，取消恢复原配色；提供精细调节、对比提示与恢复自动。在“学期与作息”填写第一教学周的**周一**日期、总周数和节次时间。
4. “宿舍 → 查询智能水电”，填写本人完美校园所绑定的校园卡账号（通常为学号）。若成功返回房间，逐一选择房间所属校区。需要先在完美校园“智能水电”里绑定自己的房间。
5. 宿舍页在线图表使用智能水电返回的“今日用量”，按房间与设备保存本机历史。设置页可启停自动采样。后台每15分钟检查是否到采样间隔：白天距上次成功约1小时、23点后约15分钟时查询；打开应用也会检查，手动查询直接记录。旧版24小时任务在升级后打开应用时取消，新的周期任务持久保存，由WorkManager管理重启。每个日期保存最后一次有效读数，保留实际时间；跨午夜的整次查询舍弃以免归错日期。手机强行停止、无网或省电限制仍可能导致缺失，不承诺准点运行。宿舍页提供最近后台尝试结果、检查按钮和系统应用设置入口。图表保留实际采样时刻及原始文本，单位按用户确认统一为 kWh，历史纯数字采样也按 kWh 展示，数值不变。此字段的重置时间及是否为全天用量尚待核实，采样值不能保证等于当天最终总耗电量。手工记录默认收起，其区间用量与在线数据分开。在线图与手工图均提供纵轴刻度、日期和点上数值；点击圆点高亮后，可在图下查看该次采样的日期、原始用量和采样时间，或手工记录的区间始末与耗电量。多条记录可横向滑动，缺失日期或未知用量不连线，不添加演示数据。
6. “校园 → 登录会话”可清除本应用内学校网页登录状态；“宿舍 → 账号 → 移除账号及在线缓存”可移除保存的水电账号。
7. 首页开始专注时，Android13+首次会申请通知权限；拒绝也可计时和记录。首页专注卡或“设置 → 专注提醒”可打开通知设置与准时提醒授权。提醒不依赖应用页面常驻；完成只记录一次，提前结束会撤销本次闹钟。通知的声音、振动与显示位置跟随系统设置；“测试提醒（10秒）”可用于返回桌面后检查通知，不计入专注记录。
8. 若桌面不提醒、返回应用才出现，可在“专注提醒 → 查看测试状态与提醒设置”核对计划、广播接收和提交系统的时间，并打开后台运行设置。小米/澎湃OS上需由本人允许后台自启动、将应用省电策略设为“无限制”；通知栏已有提醒但不弹横幅时，可通过“横幅与声音”进入本渠道设置。应用不会代改这些系统权限。

## 导入 JSON

也可以选择“从大学课表文件导入（MD / JSON）”，读取大学课表导出或外部 agent 按 `univ-timetable/v1` 模板生成的文件。机器可读 JSON 优先，其次读取 Markdown 课程明细表。导入预览中可选更新合并、整体替换、追加，以及是否应用文件内的校历和作息。无有效课程时不修改旧课表。

设置页“导出课表”会生成大学课表可读取的标准 JSON，包含课程、备注、校历与作息，不包含水电数据或账号。具体差异和两种方案边界见 [课表实现对比](docs/TIMETABLE-COMPARISON.md)。内置AI文字/截图识别、手动课程编辑、整学期列表和背景图片尚未迁移。

直接支持正方课表查询返回的 `{"kbList":[...]}`、仅包含课表条目的数组，以及以下独立格式：

```json
{
  "courses": [
    {
      "name": "格式示例课程",
      "teacher": "",
      "location": "格式示例教室",
      "day": 1,
      "weeks": [1, 3, 5],
      "sections": [1, 2],
      "campus": "LIANHUA"
    }
  ]
}
```

这是格式说明，不是学校课表。`day` 为周一=1 至周日=7，`campus` 可为 `LIANHUA`、`SONGSHAN`。解析支持单双周、分段周次及不连续节次。发现坏条目时预览会显示数量，用户可以取消；完全无有效课程时不替换旧课表。

## 构建与检查

Kotlin 2.0.21、Compose Material 3、AGP 8.7.3、Gradle 8.9、JDK 17、compile/target SDK 35；支持 Android 8.0 / API 26 及以上。

Windows 项目自带便携工具链配置脚本（下载文件按 SHA-256 验证；工具写入本项目 `.toolchain`）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\setup-android.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build.ps1
```

日常检查包括 `testDebugUnitTest`、`assembleDebug`、`lintDebug`。发布检查运行 `tools/build.ps1 -Release`，额外执行 Release 单测、R8构建与 `lintRelease`。若已有 JDK17/Android SDK，可直接配置 `JAVA_HOME` 和 `local.properties` 后使用 Gradle Wrapper。

日常调试产物：`app/build/outputs/apk/debug/app-debug.apk`。正式构建先生成未签名Release APK，由维护者使用本机私有签名材料和公开轮换证明签名；私钥不随仓库或源码ZIP分发。维护说明见[发行签名](docs/SIGNING.md)。

正式交付为 `HAUTPocket-1.0.1.apk`、`HAUTPocket-1.0.1-source.zip` 与 `SHA256SUMS.txt`，可从[GitHub Release](https://github.com/rainthink-vanilla/HAUTPocket/releases/tag/v1.0.1)下载；完整验证范围见[验证记录](docs/VERIFICATION.md)。

## 隐私与数据

- 无自建后端、广告或统计 SDK。数据仅保存在本机和学校/完美校园官方服务之间。
- 教务登录密码只填写在学校页面，不被原生代码读取。教务、查书与选座共用本机WebView会话，页面结束和后台切换时保存，可主动清除；学校使会话过期后仍需认证。见[会话说明](docs/WEB-SESSIONS.md)。
- 原生水电查询只使用本人校园卡账号；账号以 Android Keystore AES-GCM 加密保存。房间查询凭据 `roomverify` 只存在本次查询内存中，不写入课表、日志或本地快照。
- 在线房间缓存只保存凭据的 SHA-256 索引、房间名、表计显示值与更新时间。课表、房间标签、手工记录保存在应用私有存储。
- 禁用 Android 自动备份，避免系统备份带走网页会话和个人记录。卸载会清除本机数据；本版可导入/导出课表，但没有全应用数据备份/恢复界面。
- 不忽略 TLS 证书错误，不使用任意网页可调用的 JavaScript 原生桥。教务导入脚本仅在 `https://jwglxt.haut.edu.cn/jwglxt/` 上按用户操作执行。

协议与证据见 [接口与联调](docs/INTEGRATIONS.md)，构建与贡献说明见 [开发说明](docs/DEVELOPMENT.md)。
