# 口袋工大 1.0.1

教务网页登录与导入兼容性更新，版本代码19，Android8.0及以上。

## 本次变化

- 修复教务课表页面内容已加载却显示白屏的问题：仅在已核实的N9课表查询路径调整页面高度和滚动。
- 支持学校返回的“第19周”等带“第”的周次，避免漏掉课程；周次、星期和节次的有效范围仍受校验。
- 学校登录中的内部空白子框架不再误报为整页外部认证；旧HTTP教务GET跳转优先转至同站HTTPS，未核实来源继续阻止。
- 教务从系统首页进入，复用已有会话；提供学校一站式统一认证入口。教务、图书查询与选座共用应用私有WebView会话，页面结束和切到后台时主动保存。清除会话等待系统删除完成后再提示。
- 应用图标采用用户提供的新图，保留原图文字及水印，通过等比例缩放和白边适配Android自适应/圆形图标。

## 安装与会话

使用同一发行证书及签名轮换证明，覆盖安装 `HAUTPocket-1.0.1.apk`；不要先卸载。源码归档为 `HAUTPocket-1.0.1-source.zip`，下载可用 `SHA256SUMS.txt` 校验。正式包关闭调试并启用R8优化。

应用保存学校允许保留的登录状态，不保存或自动提交学校登录密码。学校主动使会话失效、修改密码、清除应用数据或认证策略变化后，仍需要重新认证，无法保证永久免登录。外部浏览器及云上工大的登录状态不自动共享。详见[网页登录会话说明](https://github.com/rainthink-vanilla/HAUTPocket/blob/main/docs/WEB-SESSIONS.md)。

## 验证范围

Debug和Release各55项单元测试通过；Release Lint无Error/Fatal。正式签名包已保留数据覆盖安装，系统确认关闭调试。用户确认：重开教务无需再次输入密码，课表查询页面能自动显示，导入预览不再出现那条无法解析；图书馆选座也无需重新登录。学校会话跨长期闲置、服务端强制到期和更换设备后的行为不在此次验收范围内。
