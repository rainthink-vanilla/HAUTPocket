# 口袋工大 1.0.0

面向河南工业大学莲花街、嵩山路校区的非官方Android校园助手，首个正式Release版本。Android8.0及以上，版本代码18。

## 主要功能

- 日列表和七天周课表；连续相同课程合并为跨节块，保留冲突课程；支持教务网页与大学课表MD/JSON两种导入、预览、合并和导出。
- 双校区宿舍配置、本人已绑定房间的智能水电查询客户端、手工记录和用电趋势。在线电量采用kWh，折线点可查看日期、原始读数与采样时间；缺失数据不伪造、不跨缺口连线。
- 底栏独立“图书馆”：原生书目检索、真实封面与放大预览、馆藏位置/索书号/借阅状态；无封面时明确提示。高级检索和座位预约通过官方页面继续，支持学校正常认证。
- 专注计时与后台完成通知，取消和完成去重；提供通知/准时提醒/后台设置入口与10秒测试。
- 统一卡片与浮动导航、可关闭动效、字体大小、主题和文字调色盘；实时预览，应用保存、取消恢复。
- 云上工大、完美校园应用跳转与学校服务入口。

## 下载与升级

下载安装`HAUTPocket-1.0.0.apk`；`HAUTPocket-1.0.0-source.zip`为源码，`SHA256SUMS.txt`用于核验下载完整性。正式APK关闭调试并使用R8优化及发行签名。

使用签名轮换证明衔接旧测试签名。旧版用户先覆盖安装，避免卸载造成课表、房间与本机历史丢失；发行证书及维护方式见[签名说明](https://github.com/rainthink-vanilla/HAUTPocket/blob/main/docs/SIGNING.md)。

## 提醒设置

Android13+需要本人允许通知；Android12+要开启准时提醒。小米/澎湃OS设备若桌面不提醒，请允许后台自启动并将应用省电策略设为“无限制”。此配置下的桌面测试提醒已在用户手机验证。声音、悬浮横幅与锁屏显示跟随系统设置；应用不会代改系统权限。

## 已知验证边界

- 教务真实账号导入、智能水电在河南工业大学当前租户下的完整账号联调尚未完成；失败时保留官方入口及本机记录。
- 用电采样是当天最后取得的有效读数，受系统后台和网络影响，不能保证等于全天最终总耗电量；无历史接口时无法次日补造昨日数据。
- 已验证真实书目搜索/详情、用户选座与认证、调色预览及后台测试通知；未穷举所有主题字号、设备、15/25/45分钟完整时长和Doze/重启场景。
- 不提供自动充值、自动抢座、校园卡转账或截图AI识课表。

## 隐私与致谢

无自建后端、广告或统计SDK；学校登录在官方网页进行，密码不由原生代码读取。水电账号通过本机Android Keystore加密，查询凭据不进入源码或发布附件。详见仓库README及验证记录。
