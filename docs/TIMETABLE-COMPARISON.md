# 课表实现对比与双方案

2026-10-27。比较本地 `univ-timetable-public` 与 `univ-timetable-publish`（两份 `timetableFile.ts` SHA-256 相同，大学课表版本1.7.2），以及口袋工大0.1.0。先检查真实代码，再做兼容适配；本次不引入新库，沿用上一轮已调研的Android技术栈。

## 原有差异

| 方面 | 本地大学课表1.7.2 | 口袋工大0.1.0 |
|---|---|---|
| 技术 | Expo / React Native / TypeScript | Kotlin / Jetpack Compose |
| 在线教务 | 不直接登录教务；`settings.jwc` 只是预留配置 | 内嵌官方WebView，用户自行登录后显式读取正方课表，待真实账号联调 |
| 文件 | .md / .json，JSON代码块优先、课程表格兜底 | 仅纯JSON，支持正方kbList及简化courses |
| 标准契约 | `univ-timetable/v1`，含meta、periods、courses | 当时未适配该契约 |
| 课程字段 | dayOfWeek / startPeriod / endPeriod / weeks / note | day / sections / weeks / campus |
| 日历与作息 | 可从文件同步 | 手动设置，文件导入不读取 |
| 导入策略 | 选课、更新合并、整体替换、追加 | 全部整体替换 |
| 更新匹配 | 课程名+星期+起始节次，另用课程名+星期兜底，可覆盖同日调整的课 | 原先没有更新合并 |
| 其他输入 | AI识别文字/截图（需自配服务），手动增删改 | 未实现 |
| 展示 | 日视图、七天周格、整学期列表、重叠课程分列 | 手动选择周与星期后显示课程列表，今日页显示课程 |
| 外观与交互 | 背景图/裁剪、主题、灵动岛、课程编辑、分享 | Material3统一界面，未移植上述个性化与编辑功能 |
| 数据位置 | AsyncStorage本机存储 | 应用私有SharedPreferences；本机存储 |

因此不能说“同一套课表代码”或“之前已有完全兼容”。两边的UI组件也无法直接互相复制运行；应共享文件契约和课程语义。

## 已实现的双方案（口袋工大0.2.0）

### A：校内网页读取

用户在官方教务网页登录 → 选学期 → 原生侧显式发起只读请求 → 同一导入预览 → 本地课表。

优点：不需要外部agent整理文件，后续可再次导入更新。限制：依赖学校页面、菜单权限和会话；仍待真实账号验证，不是无人值守实时同步。

### B：通用文件离线导入

大学课表导出，或外部agent按模板整理 → .md/.json → 同一导入预览 → 本地课表。

本次加入：大学课表标准JSON/Markdown内JSON、Markdown课程明细表；dayOfWeek与起止节次映射；文件周次、备注、学期起始日、总周数、节次作息；替换/更新合并/追加；导出 `univ-timetable/v1` JSON供大学课表读取。

两种入口共用解析后的课程模型、导入预览和离线显示。文件中的校历/作息由用户在预览里选择是否应用。更新合并以课程名+星期+全部节次+校区匹配，保留原ID；变更上课时段、删除课程或换学期建议整体替换，避免残留旧安排。

这里的合并规则与原大学课表并非逐行等价：口袋工大增加完整节次和校区条件，避免同日同名但时段/校区不同的安排互相覆盖，因此不会自动“移动”旧课到新时段。

## 明确未统一的能力

- 未把大学课表的内置AI文字/截图识别、手动课程编辑、多视图、背景主题与灵动岛搬进原生App。
- 文件格式是对规范导出文件及常见表格的兼容，不承诺复制原TS解析器所有宽松别名与猜测规则；坏数据提示并保留旧课表。最大60周、20节。
- 文件里的主题会提示未应用；学生姓名/学号不进入课表导出，水电账号、房间与会话完全不进入课表文件。
- 口袋工大支持不连续节次；导出给大学课表时拆成多个连续安排，避免把中间空节误当成有课。
- 口袋工大的campus是扩展字段，大学课表会忽略；若再经大学课表重新导出，校区须从教室名称判断或按当前校区补全，不能承诺来回导出后校区字段不丢。
- 本次不改动原大学课表工程，可继续独立使用。

## 验收方法

使用本地大学课表真实导出函数生成合成示例，再通过口袋工大的JVM测试读取；反向导出的JSON再用本地大学课表的真实解析器检查。测试同时覆盖Markdown表格、周末多天、作息和元信息、替换/合并/追加、坏文件与不连续节次。最后运行Android编译和lint。真实学校登录与Android文件选择交互仍需设备验证。
