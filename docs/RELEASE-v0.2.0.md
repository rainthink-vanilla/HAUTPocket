# 口袋工大 0.2.0 测试版

面向河南工业大学莲花街、嵩山路两个校区的非官方Android校园助手，支持Android8.0及以上。

本项目是参考 [ZZUPocket](https://github.com/3beuml/ZZUPocket) 的河南工业大学版复刻/适配实现，作为独立项目维护。**特别感谢原作者 [3beuml](https://github.com/3beuml) 开源校园助手，为本项目的功能规划、离线体验和构建方案提供参考。** 已保留原作者的版权与MIT许可声明。

## 本版功能

- 官方教务网页导入与大学课表MD/JSON文件导入两种方案，共用离线课表。
- 支持文件内校历、作息、备注；替换、更新合并、追加；反向导出标准JSON。
- 莲花街/嵩山路房间配置与读数分开保存。
- 已实现智能水电只读查询客户端、在线表计展示及独立手工记录。
- 完美校园、云上工大、教务和图书馆入口；本地专注计时。

## 验证与限制

29项单元测试、双向课表文件互通、Android编译、lint、APK包名和签名检查通过。

这是供安装联调的 **debug测试包**，尚未使用河南工业大学真实账号验证教务网页和智能水电；Android设备界面与系统交互也待检查。原生校园卡余额/流水、后台专注通知，以及大学课表的AI截图识别、多视图和主题尚未实现。

附件包含APK和SHA-256校验文件；源码可通过GitHub自动生成的Source code下载。
